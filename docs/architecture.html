Ядро агента (assistant/engine.py)

1

Классификатор намерений и сегментация

  • Сегмент по цели, цель не угадывается — unknown + уточняющий вопрос
  • Цитата-основание берётся дословно из реплик клиента
  • Смена цели → пересчёт сегмента, старая цитата остаётся в истории
2

Фильтры безопасности (Guards)

  • Отказ do_not_contact → диалог остановлен, черновика нет
  • Стоп-слова (доход, «вылечит») → escalate, без обещаний
  • Вопрос вне базы → наставнику; действия за клиента запрещены
3

Генератор карточки и черновика

  • Карточка: segment, evidence, interests, next_action, статус
  • Черновик сообщения наставнику: requires_human_approval = true
  • Номера телефонов скрыты у наставника, без путей к файлам
